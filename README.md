## Game Description
Sushi Mayhem is a top-down cooking game where the player manages a sushi kitchen on their own. Customers place different sushi orders that the player must prepare and deliver within a time limit. The player moves between different prep stations to prepare ingredients and assemble each order. See our [brainstorm doc](https://docs.google.com/document/d/1DTVT0glg7tCB541ZqvZlfYEgdzlmRlTts7fO0mwFG9g/edit?usp=sharing) for more info on our vision


### Current Target
Our current goal is to create a cohesive, working game where the player can receive customer orders, perform actions in the kitchen to prepare each order, and send out the completed items to customers.
