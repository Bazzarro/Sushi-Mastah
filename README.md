## Game Description
Sushi Mayhem is a top-down cooking game where the player manages a sushi kitchen on their own. Customers place different sushi orders that the player must prepare and deliver within a time limit. The player moves between different prep stations to prepare ingredients and assemble each order.  

### Current Target
Our current goal is to create a cohesive, working game where the player can receive customer orders, perform actions in the kitchen to prepare each order, and send out the completed items to customers.
